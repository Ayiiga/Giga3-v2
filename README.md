# Giga3 AI

**Giga3 AI is a Ghana-built AI learning and productivity platform** for students, teachers, creators and businesses. It brings study and exam preparation, AI assistance, content tools and community features into a mobile-friendly progressive web app (PWA).

Official website: https://www.giga3ai.com/

## Public products

- **GigaLearn:** study support, subject revision and practice for BECE, WASSCE and Teacher Promotion. Practice materials are learning aids, not official WAEC or GES examinations unless explicitly identified as such.
- **GigaLearn Academy:** structured courses, AI tutoring and the Technology Learning Hub.
- **AI Chat:** writing, research, coding and everyday assistance.
- **Document Studio and Creator Studio:** document creation, editing and social drafting tools.
- **GigaSocial:** creator community, posts and discovery; public Awards pages describe a platform-run initiative, not an external award granted to Giga3 AI.
- **Marketplace:** digital product listings and physical-goods enquiries. Physical delivery, shipping and checkout availability must be checked on the live product pages.

The current feature map lives in [web/lib/seo/productCatalog.ts](web/lib/seo/productCatalog.ts). The live website and [pricing page](https://www.giga3ai.com/pricing/) are the source for public availability and current prices.

## Development and checks

Use Node.js 22 and provide required environment variables through local configuration or GitHub Actions secrets. Never commit API keys.

```sh
cd web
npm ci --legacy-peer-deps
# Configure web/.env.local using web/.env.local.example
npm run lint
npm run build
npm run seo:audit
npm run check:undefined
```

The PWA is built as a static export; the output directory is `web/out`. The [Cloudflare Pages workflow](.github/workflows/pages.yml) builds and audits this output before deployment. A successful commit or PR is **not** proof of a successful live deployment.
